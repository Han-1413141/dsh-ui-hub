# UI 管家界面 / UI Hub gallery

## 当前界面

下面是插件实际渲染结果，使用 DSH 0.2.0-rc.2 官方主题样式与本地示例控件；不是原生桌面窗口的截图。

- 搜索框按控件名称、插件名或插槽筛选，匹配项自动展开。
- 常用操作集中在搜索框下：拖拽模式、自动排布、拾取元素。
- 官方与插件界面按区域分组；右侧开关控制显示状态，箭头展开位置与内部元素设置。
- 部分控件隐藏时，分组开关显示中间状态；点击后统一显示整组。
- 底部依次为撤销、重做、导出、导入、刷新和恢复默认，每个图标均有文字提示。
- 保存状态和剩余重叠数量显示在底部；列表过长时仅滚动列表，操作区保持可见。

## 编辑与恢复

位置模式包含默认、微调和浮动。输入坐标可精确定位；拖拽模式支持直接移动和右下角调整大小。拖拽期间暂停自动避让，结束后再处理重叠。

撤销与重做保留当前页面最近 30 步布局修改。整组开关、恢复默认和布局导入均可撤销。导出的 JSON 可在匹配控件身份的 Web 与桌面配置间恢复。
